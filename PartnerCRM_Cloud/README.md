# Облачная синхронизация ПАРТНЁР CRM

## Что уже добавлено
- Одинаковая CRM-страница для компьютера и Android APK.
- Подключение к Supabase по URL проекта и anon/publishable key.
- Вход через Supabase Auth (e-mail и пароль).
- Общая запись базы CRM в PostgreSQL, проверка обновлений каждые 10 секунд.
- Защита от тихой перезаписи: при одновременных изменениях CRM сообщает о конфликте версий.
- Локальная копия продолжает сохраняться на устройстве.

## Что нужно сделать один раз администратору
1. Создать проект на https://supabase.com/ и дождаться его запуска.
2. Открыть SQL Editor и выполнить целиком файл `PartnerCRM_Cloud/supabase_setup.sql`.
3. В Authentication -> Users создать учётные записи для сотрудников (или одну общую учётную запись).
4. В Project Settings -> API скопировать Project URL и anon / publishable key. **Не используйте service_role / secret key.**
5. На компьютере открыть CRM, нажать «Синхронизация», заполнить URL, anon key, e-mail и пароль первого пользователя, затем «Подключить и синхронизировать». Если облачная таблица ещё пустая, CRM загрузит туда локальную базу.
6. На телефоне и остальных компьютерах открыть ту же облачную CRM, ввести те же URL и anon key, но личный e-mail/пароль каждого сотрудника. Устройства загрузят общую облачную базу.

## Важно
- Данные синхронизируются после сохранения; устройства проверяют облако каждые 10 секунд.
- Если два сотрудника одновременно изменят базу, система не будет молча затирать одну копию: появится конфликт. Сначала выберите «Загрузить облачную базу» или, только если уверены, «Заменить облачную базу моей копией».
- Перед первым включением синхронизации рекомендуется сделать «Экспорт базы».
- Для пяти сотрудников создайте пять отдельных пользователей Supabase Auth. Не передавайте сотрудникам service_role key.
- Пока не подключены URL, anon key и учётная запись Supabase, обмен между устройствами не активируется.
