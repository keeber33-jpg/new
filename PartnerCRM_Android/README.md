# ПАРТНЁР CRM — Android 1.2

Android WebView-приложение с тем же интерфейсом CRM, что и браузерная версия. База данных общая для компьютера и телефона и хранится в Supabase.

## Подключение облака
1. Создайте Supabase project.
2. Выполните SQL из файла `supabase_setup.sql` в SQL Editor.
3. Создайте учётные записи менеджеров в Authentication → Users.
4. При первом запуске приложения укажите Project URL, anon/publishable key, email и пароль сотрудника.
5. Для первоначальной загрузки данных первым войдите с компьютера, на котором находится самая актуальная база. После этого телефон загрузит эту общую базу.

## Синхронизация
Изменения отправляются после сохранения; устройства проверяют обновления каждые 10 секунд. При одновременном редактировании CRM спрашивает, какую версию оставить. Экспорт/импорт JSON сохранён.

## Сборка
В корне репозитория настроен GitHub Actions workflow `.github/workflows/build-android.yml`. После push в `main` APK собирается автоматически и публикуется как артефакт `PartnerCRM-debug-apk`. Можно запустить вручную через Actions.
